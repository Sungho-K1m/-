# 춘천 일자리 격차 진단 (포트폴리오 데모)

춘천 청년의 희망 조건과 지역기업 공고 사이에서 **직무·임금·근무조건·역량** 중 어디가 어긋나는지 보여주는 웹 데모예요.
기업·공고·지원사업은 모두 **가상 데이터**예요. 요구사항은 [SPEC.md](SPEC.md)에 있어요.

## 실행

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 → http://localhost:3000
npm test         # 점수 계산·데이터 규칙 테스트
npm run build    # 배포 전 확인용 빌드
```

## 어디를 고치나요?

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 공고 내용, 설명 문장 | `data/jobs.json` |
| 지원 혜택 | `data/benefits.json` |
| 인접 직무와 공통 업무 | `data/adjacency.json` |
| 가중치·배지 기준 등 `[예시값]` | `src/lib/scoring.ts` 맨 위 상수 |
| 온보딩 기본값, 통근 시간 선택지 | `src/lib/profile.ts` |

- 설명 문장에는 **숫자를 직접 쓰지 않아요.** `{salaryMin}` `{salaryMax}` `{commute}` 자리표시자를 쓰면 공고 값으로 채워져요.
- 데이터를 고친 뒤 `npm test`를 돌리면, 공고 30개·기업 15곳·직무 분포·"(가상)" 표기·숫자 직접 쓰기 같은 SPEC 규칙이 깨졌는지 바로 알려줘요.
  규칙 자체를 바꾸기로 했다면 `src/lib/data.test.ts`의 기대값도 함께 고쳐요.
- 데이터 안내 화면(S5)의 숫자는 데이터와 상수에서 계산하니 따로 고칠 필요가 없어요.

## 알아둘 점

- 입력한 조건은 브라우저 탭 메모리에만 있어요. 새로고침하면 사라지고, 매칭 결과 화면이 "조건을 입력해 주세요"로 돌아가요.
- `adjacency.json`은 SPEC 예시(`"마케팅": ["영업", "사무"]`)와 달리 인접 직무마다 공통 업무 목록을 함께 담아요. 공고 상세의 "공통 업무" 표시에 필요해서예요.

## 배포 (Vercel 무료 플랜)

1. [vercel.com](https://vercel.com)에 가입하고 로그인
2. 이 폴더에서 `npx vercel` → 안내에 따라 로그인·프로젝트 생성 (설정은 기본값 그대로)
3. 공개 링크로 올릴 때는 `npx vercel --prod`

GitHub에 올려 두었다면 Vercel 대시보드에서 저장소를 가져와도 돼요. API 키나 환경변수는 필요 없어요.
